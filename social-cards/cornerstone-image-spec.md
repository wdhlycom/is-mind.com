# Cornerstone Guides — 文章配图规范（2026-08-05）

用途：为 4 篇纲领性基石文各绘制 1 张头图（正文首屏插图）。用户使用 Canva / Figma / Procreate 等工具自行绘制。

---

## 统一视觉规范（四张共用）

| 维度 | 规范 |
|---|---|
| 尺寸比例 | **3:2 横版**（推荐 1200×800px / 1800×1200px，满足文章头图与社交分享） |
| 风格 | 扁平化矢量插画 + 细线装饰；可叠加水彩/纸张纹理制造"神秘学质感"（纹理来自素材叠加，底层是矢量几何） |
| 主色调 | 深紫夜空底色 `#1a1535` → `#2a245a` 渐变（与首页深色主题一致） |
| 强调色 | 金色 `#d4af37`（线条/星点/主体轮廓）、柔金 `#f3d778`（高光） |
| 点缀 | 细金星点 ✦、月相符号（新月/满月/残月）、细线圆形/星座连线装饰 |
| 文字（如含） | Cinzel（标题衬线）/ Cormorant Garamond（说明），白色或金色；无文字更佳 |
| 留白 | 主体居中偏下，上方留 1/3 星空间，避免贴边 |
| 故事感 | 每张图含 1 个人物或 1 个可识别道具，带叙事性（不画抽象几何堆砌） |

## 各篇配图构想

### 1. The Fool's Journey（tarot/fools-journey-complete-guide）
- **主题**：愚人之旅——一个人站在悬崖边准备迈步，脚下一条金色小路蜿蜒通向远方，路上散布 3–4 个标志性站点（小塔楼、太阳、终点光环）。
- **画面内容**：中景人物背影（背包、白玫瑰）、悬崖、下方云海、金色路径像光带一样向前延伸；天空一颗大太阳（象征 The Sun 卡）。
- **风格**：扁平插画 + 金线勾勒路径；元素参照 RWS 愚人牌但现代扁平化。
- **情感**：勇气、出发、未知的可能性。

### 2. Astrology 101（astrology/astrology-101-sun-moon-rising）
- **主题**：出生星盘三要素——圆形星盘 + 太阳/月亮/上升三个高亮符号。
- **画面内容**：一个大的圆形星盘（细金线圆环、外圈十二宫分段），盘中心三个符号并排高亮：☉ 太阳（金色）、☽ 月亮（银色）、ASC 上升（星形）；背景星空。
- **风格**：扁平 + 细线图表感（类似天文图），可加黄道符号环装饰。
- **情感**：秩序、可读、神秘但可理解。

### 3. Your Energy Body 101（energy/energy-body-101）
- **主题**：精微能量系统——冥想人形 + 七个彩色脉轮点 + 气场光晕。
- **画面内容**：人物侧面盘腿冥想剪影（深色），脊柱一线七个小圆点从底到顶依次红/橙/黄/绿/蓝/靛/紫；身体外围一圈柔和光晕（径向渐变，金色→透明）；可加几道细线波纹表示能量流动。
- **风格**：扁平剪影 + 渐变光晕，颜色渐变要干净（可参照脉轮彩虹）。
- **情感**：平静、流动、身体与能量的连接。

### 4. Best Tarot Decks 2026（reviews/best-tarot-decks-beginners）
- **主题**：多副塔罗牌评测——桌面扇形展开的塔罗牌 + 一束暖光。
- **画面内容**：俯视桌面，6 副牌扇形/叠放展开（每副牌背用不同色系区分：红/金/绿/蓝/紫/白），一副翻开的牌面朝上（显示简单卡面图案）；角落一小束暖光 + 星尘。
- **风格**：扁平静物插画；牌背纹样可画简单几何（星、圆、月相）。
- **情感**：选择、质感、可触摸感。

## 绘制建议
- 先画四张的**共用背景模板**（深紫渐变 + 星点 + 月相装饰层），再分别叠加每张的主体——保证统一感、节省时间。
- Canva：用"手绘/水彩"类纹理叠加在扁平几何上，即可获得现有 cleanup 图的手绘质感。
- 出图后文件名：`<slug>-en-01.png`（如 `fools-journey-complete-guide-en-01.png`），放在对应文章目录下，并在 `index.md` 中"引言后"插入 `![](文件名)` 占位行。
