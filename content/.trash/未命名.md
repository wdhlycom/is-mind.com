# is-mind.com 视觉系统（对齐「灵性图片技能」）

> 本文件不是我凭空设计的模板，而是把你**已安装的两个技能**梳理成一张可执行的对照表：
> - 「灵性图片技能」：HTML+CSS → Chrome 截图 → PNG，5 套现成 CSS 皮肤（**不依赖 AI 文生图**）
> - 「oranum-affiliate-marketing」：Pin→Blog→Oranum 漏斗 + 板块分类 + 文案写作原则
>
> 更新：2026-07-20 — 按真实工作流重建；板块定为 5 个（**移除 Numerology & Sync**）
> 说明：视觉系统是**给风格定调**，不是硬性模板。装饰位置、CTA 变体、跨平台差异——都鼓励你自己测试变化。下面标「固定」的只有极少数真正影响品牌识别的项。

## 四、文案铁律（沿用技能原生规范，别改）

技能的核心竞争力在这，照做即可：

- **Headline 5–8 词**（玄学皮）+ **Hook 15–25 词**（科学骨），总 25–35 词
- **认知失调**：神秘学现象 × 科学/心理学名词强绑（如 "The Science of Shadow Work"）
- **触发型不结论型**：图片制造好奇缺口，结论留给文章内页
- **高智感词替换**：用 Subconscious / Cognitive / Archetype / Synchronicity，禁 Magic / Miracle
- 字数上限：Pinterest ≤80 英文词，IG ≤70
- 排版禁忌：❌纯色背景 ❌纯黑 ❌白边（一律渐变+noise）

> 你担心"标题就几个词吸引不了人"——恰恰相反。这套是 **Headline + Hook 双段**，图上有两段文字（约 25–35 词），不是只有光秃秃一个标题。信息量够，也不会挤。我上一版说"只留一行大标题"是错的，以技能规范为准。

## 五、平台 CTA 策略（图上文字不可点击的真相）

| 平台 | 图上 CTA | 真正的可点击入口 |
|------|---------|----------------|
| Pinterest | **不写**（Pin 整张已可点） | 发布时填目标 URL = 文章页 |
| IG Feed | 可写 "in bio"（聊胜于无） | 主页 bio 的 Linktree |
| IG Stories | — | **链接贴纸（真正可点，主力引流）** |

结论：别把力气花在图上写 CTA。Pinterest 靠 Pin 链接，IG 靠 Stories 贴纸 + bio。

## 六、真正需要"固定"的，只有 3 样（其余随你测）

1. 品牌标 `is-mind.com` **出现在图上**（位置/大小可测变化，但必须有）
2. 每板块**认准自己那套皮肤**（不混用，保证板块内一致）
3. 文案守 **Headline+Hook 双段结构**（这是点击率的根）

装饰位置、CTA 措辞、跨平台差异、明暗微调——**都该变、都该测**，这是灵性内容的风格，不是缺陷。

## 七、图片转视频（无需出镜，沿用你现有 PNG）

技能出的 PNG 直接进 Canva：
1. Canva → 视频 9:16 → 上传该文章 3–5 张 PNG
2. 每张加 Pan/Zoom 缓动（Ken Burns）
3. 文字层放 Headline+Hook，逐行浮现
4. 加 lo-fi / ambient BGM；片尾一张 `is-mind.com` 收尾
5. 导出 MP4 30–45 秒
- 配音可选：ElevenLabs AI 英文配音 / 你自己中文录 / 纯文字+音乐（最省事）
- 想让静图动起来：Runway/Kling，提示词 `slow cinematic zoom, floating particles, ethereal glow`
